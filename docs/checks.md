# 横断の検査の数と、マージの前に見るもの

## 横断の検査の数

`verification/check_ecosystem.js` は、いま 10 リポジトリ横断 630 項目です。

この数を書くのは、この頁だけです。
README、CI の仕事の名前、作業の手順書、現状の自己評価は、この頁を指します。
2026-11-12 まで、同じ数をいくつもの場所に書いて突き合わせていました。
検査を足すたびにその全部を直すことになり、直し忘れが起きやすかったので、一か所に減らしました。
`check_ecosystem.js` が、自分の数とこの頁の数を突き合わせます。
ほかの場所に数を書き戻すと、それも落とします。

## マージの前に見るもの

マージのコミットに開示の二行（`Co-Authored-By` と `Claude-Session`）が付いていないものが、10 リポジトリ合わせて 63 件あります。
数えているのはマージのあとです。`check_ecosystem.js` が、開示の無いマージを数えて 63 と突き合わせます。

2026-11-12 から、PR の段階でも確かめます（`.github/workflows/pr-disclosure.yml`）。
枝のコミットに Claude の `Co-Authored-By` があれば、PR の本文にも開示の行が要ります。
無ければ、その PR の検査が落ちます。

マージのコミットの本文は、PR の段階では確かめられません。
本文は、マージする側がマージの時に API へ渡すもので、それまでどこにもありません。
そこで PR の検査は、マージに渡す本文の末尾に置く二行を、枝のコミットから組み立てて Actions の要約に出します。
マージのあとの件数の検査は、そのまま残します。
PR の段階で止められるのは本文の開示までで、マージのコミットの付け忘れは、あとで数えるほうでしか止まりません。
