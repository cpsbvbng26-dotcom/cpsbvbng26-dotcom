## 先に書くこと —— この文書には構造的な限界がある

**登録簿の `ST-002` が、この文書の射程を先に塞いでいる。**

> 検証の量は、検証される中身の価値について何も言わない。この体系には、それを
> 判定できる検査が存在しない。緑の数字がいくら増えても、「これは価値が無い」とは
> 出ない。主張の水準では反証可能で、意義の水準では構造的に反証不可能である。

したがって、この文書が書けるのは**通過したか否かで決まる位置だけ**である。
研究の質や意義についての等級は、ここには書けない。**書けないことを埋めない。**

あわせて、決めごとの 6 番が「自称の肩書きを書かない」と定めている。
以下の位置づけは肩書きではない。**外部の閾値を満たしたか満たしていないかの記述であり、
それぞれに覆し方が付いている。**

## 方法

三つの決まりで書く。

1. **目盛りは外部のものだけを使う。**査読の有無、門の通過、所属、資金、学位。
   いずれも他人が定義し、他人が判定する。
2. **根拠を三つに分ける。**`紙面`（凍結された成果物・git の履歴・走らせられるコードから
   誰でも確かめられる）、`証言`（著者の言葉以外に根拠が無い）、
   `未確認`（作業環境から到達できない）。登録簿と同じ分け方である。
3. **一つの軸に一つの数だけ置く。**複数の軸をまとめた総合点は作らない。
   総合点は、作る側が重みを決められるからである。

## 貢献と到達は、別の軸である

**新しい結果としての貢献は 0 である。**Trinity-Infinity の三篇に新しい数学は無い。
`x ← DQx + (I − D)p` は定常反復であり、収束はバナッハの不動点定理から出る。
**これは著者自身が紙面と README に書いていることで、緩めない。**

**だが「貢献」は一つの軸ではない。**数学の慣行が数えるものを並べると、こうなる。

| 貢献の種類 | 分野が数えるか | この系列 |
| --- | --- | --- |
| 新しい結果 | 数える | **無い** |
| 既知の定理の新しい証明 | 数える | **無い。**バナッハの不動点定理は正しく引用して使っている（経路の 3、種別は「利用」であって再発見ではない） |
| 解説・概観 | 数える | **無い。**紙面は解説として書かれていない（`trinity-infinity/ARXIV.md` が `math.HO` を第一希望から外した理由がこれである） |
| **再発見そのもの** | **数えない** | あるが、数えられない |
| **再発見の経路の記録** | **慣行として数えない。だが、存在する** | **ある** —— [`ROUTE.md`](https://github.com/cpsbvbng26-dotcom/trinity-infinity/blob/main/ROUTE.md)、九段階、`check_route.py` の **108 項目** |

**「再発見も広義には貢献である」という言い方には、当たっている部分がある。**
当たっているのは**経路**のほうであって、再発見そのものではない。
**同じ定理に二度目に辿り着くこと自体は、分野の既知を一つも増やさない。**
だから誌に載らない。**増えているのは、辿り着き方の記録のほうである。**

論文は終点しか見せない。撤回通知も終点である。**間は構造的に残らない。**
`ROUTE.md` はそこを刻んでいる —— 生成 1、再発見 1、利用 1、再導出 2、
発見の否定 1、撤回 1、既知との衝突 1、同定 1。

**ただし、記録としての強度には限りがある。九行のうち六行は「再構成」である。**
事後に書き起こしたものであり、その時点で書かれたものではない。
**同時に記録したのは三行だけである**（経路の 7・8・9）。
**そこを書かずに経路の記録を持ち出せば、実際より強く見える。**

**そして、この経路の記録に価値があるかどうかは、ここでは決められない**（`ST-002`）。
**言えるのは、存在することと、機械で検査されていることまでである。**

| 軸 | 測るもの | この系列の位置 |
| --- | --- | --- |
| **結果としての貢献** | その分野の既知に何を足したか | **0** |
| **経路の記録** | 辿り着き方が残っているか | **九段階。うち同時記録は三行** |
| **到達** | 何を、どこまで自力でやったか | 下の表 |

到達のほうは、比較の相手を決めれば書ける。

| 比較の相手 | 位置 | 決めているもの |
| --- | --- | --- |
| 数値線形代数を専門にする者 | **下である。**結果は教科書に載っている | 既知かどうか |
| 学部で線形代数を修めた者 | **同じあたりである。**残った事実 `(DQ)ⁿ = (∏ᵢ aᵢ)·I` は学部 2〜3 年の演習の水準である | 到達した命題の水準 |

**誤りと、その直し方は、水準が違う。**犯した誤りは作用素ノルムとスペクトル半径の
取り違えで、**学部の講義が試験で問う型である。直しに使った道具はそうではない** ——
Varga (2000)、Householder (1964)、Horn & Johnson (2013) §5.6、そしてリアプノフ方程式。
**大学院の線形システム論と行列解析に属する。**

**コードは論文に同梱されていない。**三篇は同梱していると六箇所で述べているが、
配布物にそれは無い（`trinity-infinity/ERRATA.md` の `E3`）。**あるのはリポジトリの
ほうである** —— `trinity-infinity/verification/` と `trinity-operator/`。走らせられるが、
紙面の主張のとおりではない。

### そこから導けないもの

**「数学を専門にしない者より上」は、分野への貢献では一切ない。**
専門家の集団の中では、この系列は何も足していない。

**一般の読者から見て珍しいことと、分野にとって新しいことは、別の話である。**
混ぜれば、貢献 0 のほうが見えなくなる。**この節を書いた理由は、到達を足すためであって、
貢献 0 を薄めるためではない。**

## 特異な軸について

訂正の装置の規模は、この分野で普通ではない。**だが、それを位置づけに換算しない。**
`ST-002` が塞いでいるのはここである ―― 検査の数は、検査される中身について何も言わない。

**装置について言えるのは、装置が動いているということだけである。**
数はすべて走らせて出したものであり、名乗った数と実際が合わなければ検査が落ちる。
そこまでが限界である。
