# 研究者としての位置 —— 2026年9月12日時点の現状評価

**これは現状評価である。日付を伴わない評価は、いつの話か決まらない。**
`2026-09-12` 時点で確かめられたことだけを書いてある。

**この文書は、著者が自分をどこに置けるかを、外部が決めた尺度に当てて書いたものである。**
自分で等級を決めたものではない。等級の目盛りは、どれも他人が引いたものを使う。

`check_ecosystem.js` が、ここに書いた数を実際と突き合わせる。片方だけを動かせば落ちる。

**日付も突き合わせる。**上に書いた `2026-09-12` は、この文書を最後に直したコミットの
日付と一致していなければならない。中身を直して日付を据え置くと落ちる。
`external-evaluations.md` の 8 番と同じ扱いである —— 日付は手で決めるものではなく、
git が持っているものである。**古い評価が現状評価の顔で残ることを、これで止める。**

## 先に書くこと —— この文書には構造的な限界がある

**登録簿の `ST-002` が、この文書の射程を先に塞いでいる。**

> 検証の量は、検証される中身の価値について何も言わない。この体系には、それを
> 判定できる検査が存在しない。緑の数字がいくら増えても、「これは価値が無い」とは
> 出ない。主張の水準では反証可能で、意義の水準では構造的に反証不可能である。

したがって、この文書が書けるのは**通過したか否かで決まる位置だけ**である。
研究の質や意義についての等級は、ここには書けない。**書けないことを埋めない。**

あわせて、決めごとの 6 番が「自称の肩書きを書かない」と定めている。
以下の位置づけは肩書きではない。**外部の閾値を満たしたか満たしていないかの記述であり、
それぞれに覆し方が付いている。**

## 方法

三つの決まりで書く。

1. **目盛りは外部のものだけを使う。**査読の有無、門の通過、所属、資金、学位。
   いずれも他人が定義し、他人が判定する。
2. **根拠を三つに分ける。**`紙面`（凍結された成果物・git の履歴・走らせられるコードから
   誰でも確かめられる）、`証言`（著者の言葉以外に根拠が無い）、
   `未確認`（作業環境から到達できない）。登録簿と同じ分け方である。
3. **一つの軸に一つの数だけ置く。重みつきの総合点は作らない。**
   重みは作る側が決められるからである。**総合のティアだけは置く。**
   ただし平均ではなく、**最も低い分野に合わせる**（後述）。最低に合わせる規則には、
   決める余地が無い。

## 相対ティア

**このティアは、質の等級ではない。**`ST-002` が質の等級を塞いでいる。
ここで測るのは**誰がどう通したか**だけである。段の定義に、こちらの判断は入らない。

### 段の基準

| ティア | 基準 —— 誰がどう通したか |
| --- | --- |
| **EX** | 分野の標準参照に取り込まれている。教科書や総説が標準として引く |
| **SSS** | 分野の最上位誌に載り、広く引かれている |
| **SS** | 分野の最上位誌に載っている（査読通過） |
| **S** | 定評のある査読誌に載っている |
| **A** | 査読誌に載っている（誌の格を問わない） |
| **B** | 査読に出し、**査読者の報告を受けている**（受理には至らない） |
| **C** | **受け付けの門を、人が見て通した**プレプリントがある |
| **D** | **DOI つきで公開しているが、人の選別を通っていない**（自己登録のみ） |
| **E** | 公開しているが、恒久識別子が無い |
| **F** | 公開していない |

**A と B の境目に、査読があるかどうかが入っている。**そこを越えていない。
**C と D の境目は、人が見たかどうかである。**

### 分野ごとのティア

| 分野 | ティア | 根拠 |
| --- | --- | --- |
| **数学** | **C** | Trinity-Infinity Series II が SSRN の受け付けを通っている。残る二篇は自己登録のみ |

**総合を最高の分野に合わせない。**それをすると、通っていない分野の不在が消える。
**最低に合わせる規則には、決める余地が無い。**

### この表について言えないこと

**C であることは、C の内容だという意味ではない。**受け付けの門が見たのは主題と体裁で、
論証の当否は見ていない。**段は、通った門の種類しか表さない。**

`B` に届いていないのは、査読に出していないからである。**出して落ちたのではない。**
出していない段を「届かなかった」と読むのは、この表の読み方として誤りである。

### 免責 —— この段は、娯楽の形式を借りている

**`EX` から `F` までの並びは、学術の世界のどこにも存在しない。**遊戯の等級表の形式を
借りたものである。学会も学術誌も評価機関も、この段を使っていない。
**形式は著者が持ち込んだものである。**

分けて読む必要がある。

| | |
| --- | --- |
| **動かないもの** | 通過と却下の事実。査読 **0 篇**。SSRN **3 通過 1 却下**。PhilArchive **2 通過**。いずれも機械が数え直している |
| **著者が決めたもの** | 段をいくつに切るか。境目をどこに置くか。`EX` から `F` という呼び方。総合を最低に合わせるという規則 |

**事実は動かせないが、段割りは別の作り方ができる。**同じ事実から違う表を作ることは可能である。
**その意味で、この評価は絶対ではない。**

**普遍でもない。**分野ごとに門の作りが違う。暗号研究では `Cryptology ePrint Archive` が、
数学では arXiv が既定の入口であり、そこを通っていないことの意味は分野ごとに違う。
**この段割りは、この著者の成果物に当てるために作ってある。**他の分野にそのまま当てれば、
位置を誤る。

**他人を測る物差しではない。**ここに並ぶ段は、著者一人の公開物についてのものである。
**他の誰も、この表に載ることに同意していない。**他人をこの段に当てて上下を言うために
作ったものではない。そう使われるなら、それは誤用である。

**価値については何も言わない。**`ST-002` が塞いでいる。`C` は `C` の内容だという意味ではない。

**それでも置いてある理由は一つである。**段は、他人が通したときにしか上がらない。
**自分では上げられない形にしてある。**娯楽の形式を借りているのは、そこを読みやすく
するためであって、結論を軽くするためではない。

### この表の動き方

**ティアは `papers.json` から計算する。**書いた段と、記録から計算した段が違えば
`check_ecosystem.js` が落ちる。手で上げられない。

- ある分野の論文が一篇でも **SSRN の所在を持てば、その分野は `C`** になる
- どれも持たなければ、DOI がある限り **`D`**
- 査読を通った論文が一篇でも出れば、**`A` 以上を名乗れるようになる。いまは 0 篇である**

## 特異な軸について

訂正の装置の規模は、この分野で普通ではない。**だが、それを位置づけに換算しない。**
`ST-002` が塞いでいるのはここである ―― 検査の数は、検査される中身について何も言わない。

**装置について言えるのは、装置が動いているということだけである。**
数はすべて走らせて出したものであり、名乗った数と実際が合わなければ検査が落ちる。
そこまでが限界である。
