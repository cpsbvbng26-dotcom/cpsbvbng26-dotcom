# サイトの決まり

研究の系列のサイトに共通の決まりです。
2026-11-11 に置きました。
百本ノック四の 321〜328・331・332 の答えです。
このリポジトリの頁については、`verification/check_site.js` と `verification/check_keyboard.js` が数えて止めます。
サイトをまたぐ分は `verification/check_ecosystem.js` が見ます。

## 文字の大きさと狭い画面

ブラウザで文字を 200% にしても、横に流れ出さないことを決まりにします。
幅 360 px の画面でも、横に流れ出さないことを決まりにします。
キーボードの検査（ブラウザを起こす検査）が、全頁を 360 px と、文字 200% の二通りで開いて、頁の幅が画面の幅を超えないことを測ります。

## 色

文字と背景の比は、WCAG の基準（本文 4.5:1、大きい文字 3:1）を下回らないことを決まりにします。
明るい側と暗い側の両方で測ります。
測るのは `verification/check_contrast.js` です。

## 暗い側

端末の設定（`prefers-color-scheme`）に従います。
切り替えの釦を置く頁では、選んだ側を覚えます。
暗い側の色は、明るい側と同じ名前の変数を置き換える形で決めます。

## 画像の代替テキスト

書くのは、何の画像かと、その画像でしか伝わらないことです。
書かないのは、「画像」「写真」という語そのものと、周りの本文の繰り返しです。
飾りの画像は `alt=""` にします。
顔写真は「誰の顔写真か」だけを書きます。

## 頁の重さ

一つの頁（HTML 一枚）は 200,000 バイトまでとします。
一枚の画像は 100,000 バイトまでとします。
通信の遅い人のためです。

## 言語の切り替え

切り替えは、頁の上の欄（ナビ）に置きます。
文字は、切り替え先の言語の名をその言語で書きます（English、日本語、Deutsch、Français、Italiano）。

## 頁の下の欄

頁の下の欄には、運営者の名（© の行）、連絡の道（GitHub の issue）、免責事項への道を置きます。
個人の連絡先は置きません。
研究の系列のサイトと、創作のサイトは、互いにつなぎません。

## sitemap・robots・canonical

配っているサイトには、`sitemap.xml` と `robots.txt` を置きます。
頁には正の URL（`<link rel="canonical">`）を置きます。
404 の頁は例外です。

## 外への要求

頁は外へ要求を出しません。
CSP は `default-src 'none'` から始め、`'unsafe-inline'` を使いません。
スクリプトとスタイルは、ハッシュで許すか、同じ場所のファイルに置きます。
