# 用語集

同じものを、リポジトリごとに別の語で呼ばないための表です。
左の列の語を使います。中の列の語は使いません。
`check_ecosystem.js` が、この表を読み、研究のリポジトリと Sophaxis・deposit-check の散文に中の列の語が無いことを確かめます。

見ないところは、CLAUDE.md、`papers/` の翻刻、`examples/`、英語の文書、引用（`>` の行）、鉤括弧と二重鉤括弧の中、コードの囲みとバッククォートの中です。
他人の語や画面の名前は、鉤括弧に入れて書きます。

| 使う語 | 使わない語 | 何を指すか |
| --- | --- | --- |
| 判断 | モデレーションの決定、受理の決定、却下の決定、掲載の決定 | モデレーターが投稿について下すもの |
| 正誤表 | 訂正表、エラッタ、正誤一覧 | 公開物の誤りと、その扱いの記録 |
| 凍結 | フリーズ | 公開した版を改変も再生成もしない扱い |
| 概念 DOI | コンセプト DOI、コンセプトDOI | Zenodo の、すべての版をまとめた DOI |
| 版の DOI | バージョン DOI、バージョンDOI、版DOI | Zenodo の、ある版だけを指す DOI |
| 学部一年次 | 一回生、学部1年 | 規則 15 が線を引く時期 |
| プレプリント | 予稿 | 査読前に公開した稿 |
| 要旨 | 抄録 | 論文の冒頭の短いまとめ |
| リポジトリ | レポジトリ | GitHub の置き場 |
| メタデータ | メタ情報 | 記録の書誌の欄 |

語を足すときは、この表に行を足します。
使わない語が散文に残っていれば、検査が落ちます。
