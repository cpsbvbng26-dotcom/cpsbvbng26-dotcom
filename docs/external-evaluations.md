# 外部からの評価

いま 9 件。

この文書は、外部の場から受けた評価を記録するためのものです。
**評価が来る前に作ってあります**。あとから作ると、都合の悪いものだけ載せない、が
できてしまう。器を先に固定しておけば、それができなくなります。

---

## 決めごと

破ると記録の意味が消える順に並べてあります。

1. **査読と呼びません**。公開している論文はいずれも査読を受けていません。
   DOI があることは、査読を受けたことを意味しません。外部の場が「ピアレビュー」を
   名乗っていても、こちらの記録では査読と書きません。
2. **丸写ししません**。評価文は書いた側のものです。このリポジトリは CC BY 4.0
   なので、丸写しは他人の文章を勝手に再配布することになります。**引用は短く、
   原文どおり、出典を添えて**。地の文はこちらで書きます。
3. **褒めた箇所だけ載せません**。指摘も同じ表に入れます。片方だけ載せた時点で、
   これは記録ではなく宣伝です。
4. **検証していないものは、検証していないと書きます**。外部の評価は、こちらで
   確かめていない主張の塊です。当たっていない指摘を「当たった」と書きません。
5. **人が書いたものと、機械が出したものを分ける**。表の「種別」欄がそれです。
6. **件数を機械で数えます**。下の表の行数と冒頭の「いま NN 件」が食い違えば、
   横断の検査が落ちます。
7. **出典が消えるものは、証言として扱う**。一回きりのリンクやメールで届いた評価は、
   そのうち辿れなくなります。**死んだリンクは、証拠のふりをした穴です**。書きません。
   代わりに `第三者` の欄に「確かめられない」と書きます。載せないのではなく、
   確かめられないと書いて載せます。
8. **日付を手で書きません**。その行を足したコミットの日付が日付です。
   git から取れるものを手で打つと、打ち間違いと詐称の余地だけが増える。

## 使っている場

正式名称は **Stanford Agentic Reviewer**（`paperreview.ai`）。下の表の七件はここから
出ています。残る一件は Grok（xAI）で、こちらは論文への評価ではなく、この記録群全体への
評価です。

凍結済みの PDF を掛け、返ってきた指摘を一つずつ当たって記録しています。当てたものも、
新しく出したものも、外したものも、作ったものも残します。**査読とは呼ばない**（決めごと 1）。

開発は Yixing Jiang と Andrew Ng。arXiv から関連する先行研究を引き、それに接地させた
講評を返す作りだと公表されています。

### 公表されている数は、こちらで確かめていない

作業環境から `paperreview.ai` に届きません。GitHub 以外は egress proxy が塞いでいます。
下は検索結果から取った要約であり、**原文に当たっていません**。

| 公表されているとされる内容 | こちらの検証 |
| --- | --- |
| 人の査読者どうしの順位相関が 0.41、機械と人の相関が 0.42 | 未確認 |
| ICLR 2025 の投稿 300 件で評価した（150 件で学習、147 件で試験） | 未確認 |
| arXiv に接地するため、AI 分野では精度が高く、他分野では落ちる | 未確認 |

三つめが、この記録にとっていちばん重い。ここで出している哲学の三篇は、arXiv に載る
種類の論文ではありません。Trinity-Infinity の三篇も、arXiv の機械学習の主流にある形では
ありません。どちらも接地の材料が薄い側に当たります。

### だから、こう扱う

- 当てた指摘は当てたと書きます。実際に `E6` を独立に当て、`(DP)³` を独立に導いた
  （登録簿の `EX-004`・`EX-005`）
- 外した指摘は外したと書きます。実在しない誤植を一つ作った
- 数が人に近いことは、この用途で人に近いことを意味しません。**精度が落ちる側の分野で
  使っているという前提を、消さない**

**場** —— 評価を出した先の名前。URL は書きません。消えるものを所在として書くと、
あとから開けない穴が残ります。

**種別** —— `人` は人間が書いたもの。`機械` は言語モデルなどが出力したもの。
どちらか分からないものは `不明` と書きます。推測で埋めません。

**第三者** —— `確かめられる` は、いま誰でも原文に辿り着ける場合。
`確かめられない` は、出典が消えたか、最初から一回きりだった場合。
後者は著者の言葉以外に根拠がありません。反証もできません。

**こちらの検証** —— `未検証` / `確認した` / `当たらない`。既定は `未検証` です。

**日付はありません**。その行を足したコミットの日付が日付です。`git log` で辿れます。

### Grok — この記録群全体

**この評価は論文についてではありません**。この記録群と著者の位置づけについて、外から
まとめたものです。やり取りは X 上で行われ、**出典は残らない**（決めごと 7）。

#### 外したもの

電子書籍を、現行の普及版として扱いました。「Amazon 向けの一般書が、改訂論文が削った
世界観を再び広く語り直している」と述べました。その時点で書籍は販売停止になっていました。
指摘を示したところ、Grok は評価を撤回しています。

#### 当てたもの

**外したこと自体が、この記録の穴を出しました**。販売停止は登録簿の `BK-001` にしか書いて
おらず、論文の README にもトップにも出ていませんでした。**登録簿の奥にしか無いものは、
外からは見つかりません**。題名を五つの面に出し、横断の検査で固定しました。

**削除が検証可能性を下げることも指摘しています**。凍結された PDF は残してあるので何を
撤回したかを第三者が確かめられるが、書籍についてはそれができません。**「消さない」方針の
唯一の例外です**。この点は `BK-001` に既に書いてあり、指摘と一致します。

#### 新しく出したもの

この系列を「生成モデルの実験」と読む見方を示し、同時にその読みの弱点を挙げました。

> 実験なら、仮説・手続き・失敗条件が先に要る。こちらは先に論文として出し、あとから
> 実験記録に組み替えています。

**これは当たっています**。`ROUTE.md` の九段階のうち六段階は再構成であり、この系列で
起きたことを「数学的再発見」と規定したのは最終段階の 2026年9月8日です。
**枠組みが先にあり、実験の枠は後から掛けました**。したがってこの記録は、自らを実験とは
呼んでいません。反論として先に立ててある（[objections.md](objections.md) の反論 4）。

### 経路が二つある

DOI で受け付ける場と、PDF を直接受け付ける場では、出せる範囲が違います。

**DOI で受け付ける場**。受け付けたのは SSRN の DOI だけでした。Zenodo の DOI は
対象外です。SSRN の DOI は Crossref、Zenodo の DOI は DataCite が発行しています。
**どちらの登録機関を見ているかで、受け付ける範囲が変わる**。確かめたのは
「通ったかどうか」であって、相手の仕組みそのものは確かめていません。

SSRN 版があるのは二篇だけなので、この経路で出せるのは二篇です。

| 論文 | SSRN 版 | この経路 |
| --- | --- | --- |
| The Nobility and Exemplarity of the Celibate Individual | あり | **出せる** |
| Manifesto of Imperial Selfhood | あり | **出せる** |
| Fragmentarian Spiritual Individualism | 無い | 出せない |
| Trinity-Infinity Series I・II・III | 無い | 出せない |
| A Naval Gazette Entry for Lieutenant Otani Tsune | 無い | 出せない |

**PDF を直接受け付ける場**。識別子を要求しません。Stanford ML Group の
Agentic Reviewer（paperreview.ai）がこれで、PDF を上げるだけで構造化された批評が
返ります。無料です。DOI の登録機関の違いに縛られません。

したがって、上の表で「出せない」となっている六本も、この経路なら出せます。
とりわけ Trinity-Infinity の三本は、この道具が得意とする領域（機械学習・計算機科学）に

paperreview.ai そのものには到達していない（作業環境の egress proxy が塞いでいる）。
無料であること・入力の制限・返る内容は、使う前に本人が確かめること。

**器の格は本物です**。だから本丸に見えるのは当然で、だから食い違いの代償が大きい。

器は国の機関。中身は自己申告です。この二つは別で、
上の「登録の審査 —— 中身の審査ではない」がその区別を書いています。
researchmap が見たのは登録要件であって、論文の中身ではありません。

権威があるのは登録の資格の側で、書いたものの質の側ではありません。
そして国の機関が運営しているぶん、外から来た人は後者にも権威が及んでいると読みます。

そのうえで、researchmap は**写しである** —— 内容は Zenodo と ORCID から写したものです。

**写しが本丸に見える構えは、食い違いが起きた瞬間に壊れる**。researchmap 側に
古い記述が一つ残れば、外から来た人はそれを正として読みます。**Vercel が古い科目名を
出していたのと同じ形です**。あちらは写しが入口に立っていた話で、
こちらは写しが本丸に見えている話です。

**上の節に足りていなかったのは、この軸です**。そこに書いてあるのは
DOI が割れている話だけで、どこが本丸に見えるかは書いていませんでした。

規則は既にあります。表示がありません。

> これらに食い違いが見つかったときは、Zenodo と ORCID に合わせて外部側を直す。逆はしない。

**researchmap 自身が「これは写しである」と言っていません**。HAL も PhilPapers も
同じです。出丸が三つあって、どれも自分が出丸だと名乗っていません。

**直すのは利用者の手になります**。作業環境からどこへも届きません。各頁の自己紹介か
備考に、正本の所在を一行入れる形になります。まだ入れていません。

### この観察を受けて、規定を書き換えた

2026年9月17日、[canonical-sources.md](canonical-sources.md) の「本丸は三つある」で
本丸と正本を分けました。

**それまでは三つを「入口」と呼んでいた**。呼び方が実際と合っていなかった ——
人を探しに来た者は、そこに着いて、そこで止まる。入口ではなく着地点です。

| | 何を決めるか |
| --- | --- |
| **正本** | 写しが食い違ったとき、どちらが勝つか |
| **本丸** | 人を探しに来た者が、どこに着くか |

この二つを分けたので、「写しが本丸に見える」はもう矛盾ではありません。
**本丸は写しであってよい**。正本に勝てないことが書いてあれば足りる。

**Zenodo は本丸から外れました**。プロフィールの頁を持たないためです。
論文の正本ではあるが、着いても人は出てきません。利用者の指摘による。

**運営母体を全部調べました**。researchmap は JST と NII、HAL は CNRS の
CCSD、PhilPeople は PhilPapers Foundation と Western University の
Centre for Digital Philosophy、SSRN は Elsevier、Google Scholar は Google、
**Kudos は Kudos Innovations Ltd** です。六つのうち四つは国の機関ではありません。

**SSRN・Google Scholar・Kudos を本丸に加えたのは、プロフィールの頁を持つからである**
（いずれも利用者の指摘）。加えた結果、本丸の三つが営利企業の手に入りました。

**そしてその三つは、同じ手が計測も持っています**。Elsevier は SSRN と PlumX、
Google は Google Scholar と被引用数、Kudos は面と共有の経路の数です。
**本丸と計測が同じ手にある例が三つになった**。置いた先が数えているとき、
その数は独立した外部の目ではありません。これは規則ではなく、いま三つがそうだという
だけです。
