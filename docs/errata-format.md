# 正誤表の書式

研究の系列の正誤表（各リポジトリの `ERRATA.md`）に共通の書式です。
2026-11-11 に置きました。
百本ノック四の 343 の答えです。

## 項目の頭

一件ごとに、次の形の見出しを置きます。

```
## E<番号> — <何が誤っているかを一文で>
```

番号は E1 から欠けずに続けます。
消した番号は再び使いません。
誤りではないが記録しておくことは、別の節に N の番号で置きます。

## 項目の欄

新しく足す項目には、見出しのすぐ下に次の表を置きます。

| 欄 | 書くこと |
| --- | --- |
| 日付 | 見つけた日（YYYY-MM-DD） |
| 重さ | 高・中・低のどれか |
| 見つけた人 | 著者・機械の検査・読者のどれか（読者の名は、本人が望んだときだけ書く） |
| 該当 | 紙面のどこか（節・頁・参考文献の番号） |
| 印字 | 紙面に印字されているとおりの文 |
| 正 | 正しい形 |

日付・重さ・見つけた人は、訂正の登録簿（`self-correction` の `register.toml`）にも同じ値で書きます。
登録簿のほうが、機械で読む正です。

## 既にある項目

2026-11-11 より前の項目は、書いた時点の形のまま残します。
欄を後から足すときは、登録簿の値を写します。
写せない欄は「記録していない」と書きます。

## 知らせの様式

外から誤りを知らせる様式は、各リポジトリの `.github/ISSUE_TEMPLATE/error-report.yml` に置いた一つです。
様式の「見つけた人」の欄が、正誤表の同じ欄に入ります。
`check_ecosystem.js` が、10 のリポジトリの様式が一字一句同じかを見ます。
