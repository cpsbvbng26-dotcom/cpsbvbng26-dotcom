# 先に立てておく反論

この文書は、この記録群に向けられる反論のうち、**当たっているもの**を先に書き出した
ものです。反論を黙らせるために置いてあるのではありません。認めるところを先に書きます。

五つとも、実際に受けた形のまま置いてあります。言い換えて弱めません。

答えの形は毎回同じです。

1. **認めるところ** —— 反論のどこが当たっているか
2. **それでも残ること** —— 機械で確かめられる事実だけ
3. **この答えの崩し方** —— 何を一件示せば、この答えが倒れるか

三つめが無い答えは、反論ではなく宣伝です。

---

## 反論 1 —— 「重要なのは内容じゃないのか」

### 認めるところ

**当たっています**。そしてこの体系には、内容の価値を判定できる検査が一つもありません。

登録簿の `ST-002` に `open`（解けていない）として置いてあります。緑の数字がいくら
増えても、「これは価値が無い」とは出ません。主張の水準では反証可能で、意義の水準では
構造的に反証不可能です。解き方は分かっていません。

数を増やしても解けないことだけは分かっています。

### それでも残ること

内容の誤りに向き合った記録が、消さずに残っています。撤回が 5 件あります。

| | |
| --- | --- |
| `WD-002` | 三人ゲームの利得を 4 セルの表で示していました。三人・二戦略なら 2³ = 8 通りある |
| `WD-003` | 離散反復に、リアプノフ微分と LaSalle の不変性原理という連続時間の道具を当てていた |
| `WD-001` | 「98.7% の試行で確認」。再現できるコードも乱数種も無い |
| `WD-004` | AI アライメント・気候政策・ガバナンスへの応用 |
| `TI-001` | 収束の条件を作用素ノルムで述べていました。‖DQ‖₂ < 1 は十分条件にすぎず、必要十分は ρ(DQ) < 1 のほうである |

**これらは書式の誤りではありません**。定理と論証の誤りです。

**そして、見つけたのは機械ではありません**。登録簿の `found_by` は 5 件とも「著者」です。
機械が数学の誤りを見つけたと書いたことは一度もありません。

**機械の役目は別のところにあります**。撤回した主張が静かに復活しないこと、印字された
数値がずれないこと、「解決しない」と決めた項目が「解決済み」に書き換わらないこと。
つまり検査は、内容の代わりではありません。内容について一度認めたことを、後から
取り消せなくする装置です。

### この答えの崩し方

撤回した主張が、いまも公開物のどこかで生きている箇所を一つ示します。
あるいは、登録簿が誤りを実際より小さく書いている箇所を一つ示します。どちらも一件でよい。

## 反論 2 —— 「AI 使用併記は AI を著者にしないぞ」

### 認めるところ

**当たっています**。併記は著者性を与えません。免責にもなりません。

そして、この体系は AI を著者にしていません。それは方針として書いてあるだけで、
書いてあること自体は何の保証にもなりません。

### それでも残ること

開示を盾に使っていないことは、**開示そのものの不足を自分で記録している**ことで
見える。二件あります。

| | |
| --- | --- |
| `E5` | 三篇の開示文は AI にさせた作業を列挙している。その列挙に翻訳が無い。英文は AI 翻訳である |
| `E7` | M の開示文が「AI は捏造していない」と断言している。同じ段落が、参考文献の照合も AI がやったと述べている。著者は原典に当たっていないので、この断言は AI 自身の報告に乗っている |

加えて `E6` —— 引用した原典に著者は当たっていません。英語版の README には
`The papers were not independently derived by a human` と書いてあります。

併記で足りると考えている書き手は、この三つを自分からは書きません。

### この答えの崩し方

開示が、実際にさせた作業より狭く読めるように書かれている箇所を一つ示します。
あるいは `E5`・`E6`・`E7` のいずれかが消されたことを示します。消えれば検査が落ちます。

## 反論 3 —— 「人権宣言でもしてるつもりか」

### 認めるところ

語調については当たっています。「個人帝国主義」「マニフェスト」「高貴さ」「範例」。
大きい語です。

**この語調は擁護しません**。凍結された紙面のものであり、もう直せません。

### それでも残ること

語調と射程は別です。射程は紙面自身が狭く切っています。

| | |
| --- | --- |
| 皇帝主義 | `strictly reflexive`（反照的のみ）。他者への支配を含まないと冒頭が明示している |
| 独身論 | 結論は `exemplary`（範例）であって、普遍的な義務ではないと第5節が明示している |
| 断章論 | 断片は修復すべき傷ではなく、住まうための規律の対象です。他人に課していない |

三篇とも、他者に義務を課していません。宣言の形をとっていません。

記録の側の語調は、紙面とは別に定めてあります。自称の肩書きは機械で禁止してあり、
禁じた語は各リポジトリの `check_text` に並べてあります。外部の評価を査読とも呼びません。

### この答えの崩し方

三篇のいずれかが、自ら宣言した射程を超えて他者に義務を課している箇所を一つ示します。
あるいは、記録の側が `check_text` の禁じた語を使っている箇所を一つ示します。

## 反論 4 —— 「これは実験なんでしょ？」

### 認めるところ

当たっています。実験の体をなしていません。

実験と呼ぶなら、仮説と手続きと失敗条件が先に要ります。ここは違います。**先に論文として
公開し、あとから実験の枠を掛けました**。`ROUTE.md` の九段階のうち六段階は再構成であり、
この系列で起きたことを「数学的再発見」と規定したのは、最終段階の 2026年9月8日です。

**だからこの記録は、自らを実験とは呼んでいません**。呼べば、先に置いていなかったものを
先に置いていたことにします。

### それでも残ること

枠を後から掛けたことと、経路が残っていることは別です。

| | |
| --- | --- |
| 後から掛けたもの | 「数学的再発見」という規定、九段階という整理 |
| 後から掛けられないもの | 凍結された PDF の日付（Zenodo が持つ）、git の履歴 |

段階 1〜6 は Zenodo の PDF、段階 7〜9 は git の履歴に紐づいています。
**どちらも著者が書き換えられません**。経路を都合よく引き直すことはできません。

そして再構成であることは、隠さずに `ROUTE.md` に書いてある —— 九段階のうち六段階が
再構成で、同時に記録したのは三段階だけです。その時点で何を考えていたかは推定で
あって記録ではない、とも書いてあります。

### この答えの崩し方

日付の順序が実際と違う例を一つ示します。あるいは、同時記録だと書いてある段階 7・8・9 の
いずれかについて、git の履歴がそれより後であることを示します。

## 反論 5 —— 「誠実さと免疫が同じ装置になっている」

2026-09-19 に、Grok（xAI）から受けた指摘です。**この文書でいちばん重い反論です。**

### 認めるところ

当たっています。構造がそうなっています。

外から手続きの穴を突いても、登録簿に「もう記録済み」の項目があります。未検証の引用
（`PH-007`）、AI が割り当てた出典を原典照合していないこと、翻訳が機械生成だと当初
開示しなかったこと。どれも `unresolvable` として残してあります。**残してあるから誠実に
見え、残してあるから同じ点で崩れません。** 誠実さと免疫が同じ装置から出ています。

**そして、この節を書くこと自体が同じ装置の動作です。** 反論を受けて、反論を登録簿の
隣に置いています。**この反論は、それ自体を材料にされます。**

### それでも残ること

装置の向きは、一つだけ非対称です。**登録簿は過去にしか効きません。**

92 件はすべて、起きたあとに書いたものです。33 件は再構成で、同時に記録したのは 59 件。
**どの項目も、書いた時点で結果が出ています。** 結果が出たものを記録する装置は、
結果を吸収できます。結果が出ていないものは吸収できません。

だから残るのは一点です。**この記録は、まだ一度も自分の予告で負けていません。**
予告そのものを置いていないからです。

### この答えの崩し方

**先に失敗条件を書いて、実際に失敗させます。**

`docs/predictions.md` に、結果が出ていない予告と、その失敗条件と、期限を置きました。
**結果が出る前に書いたことは、コミットの日付で確かめられます。**

- 予告のいずれかが失敗し、その項目が `失敗` として残れば、この装置は過去だけでなく
  自分の予告でも負けたことになります。
- 逆に、予告が失敗したときに記録が書き換わるか、失敗条件が緩められれば、
  **免疫のほうが勝ったことになります。**その場合は、この反論が正しかったと決まります。

**どちらに転んでも、判定は外から見えます。** 予告は git に入っていて、こちらから
書き換えられません。
