# 先に立てておく反論

この文書は、この記録群に向けられる反論のうち、**当たっているもの**を先に書き出した
ものである。反論を黙らせるために置いてあるのではない。認めるところを先に書く。

三つとも、実際に受けた形のまま置く。言い換えて弱めない。

**答えの形は毎回同じである。**

1. **認めるところ** —— 反論のどこが当たっているか
2. **それでも残ること** —— 機械で確かめられる事実だけ
3. **この答えの崩し方** —— 何を一件示せば、この答えが倒れるか

三つめが無い答えは、反論ではなく宣伝である。

---

## 反論 1 —— 「重要なのは内容じゃないのか」

### 認めるところ

**当たっている。**そしてこの体系には、内容の価値を判定できる検査が一つも無い。

登録簿の `ST-002` に `open`（解けていない）として置いてある。緑の数字がいくら
増えても、「これは価値が無い」とは出ない。主張の水準では反証可能で、意義の水準では
構造的に反証不可能である。解き方は分かっていない。

**数を増やしても解けないことだけは分かっている。**

### それでも残ること

内容の誤りに向き合った記録が、消さずに残っている。撤回が 5 件ある。

| | |
| --- | --- |
| `WD-002` | 三人ゲームの利得を 4 セルの表で示した。三人・二戦略なら 2³ = 8 通りある |
| `WD-003` | 離散反復に、リアプノフ微分と LaSalle の不変性原理という連続時間の道具を当てていた |
| `WD-001` | 「98.7% の試行で確認」。再現できるコードも乱数種も無い |
| `WD-004` | AI アライメント・気候政策・ガバナンスへの応用 |
| `TI-001` | 収束の条件を作用素ノルムで述べていた。‖DQ‖₂ < 1 は十分条件にすぎず、必要十分は ρ(DQ) < 1 のほうである |

**これらは書式の誤りではない。**定理と論証の誤りである。

**そして、見つけたのは機械ではない。**登録簿の `found_by` は 5 件とも「著者」である。
機械が数学の誤りを見つけたと書いたことは一度も無い。

**機械の役目は別のところにある。**撤回した主張が静かに復活しないこと、印字された
数値がずれないこと、「解決しない」と決めた項目が「解決済み」に書き換わらないこと。
つまり検査は、内容の代わりではない。**内容について一度認めたことを、後から
取り消せなくする装置である。**

### この答えの崩し方

撤回した主張が、いまも公開物のどこかで生きている箇所を一つ示す。
あるいは、登録簿が誤りを実際より小さく書いている箇所を一つ示す。どちらも一件でよい。

## 反論 2 —— 「AI 使用併記は AI を著者にしないぞ」

### 認めるところ

**当たっている。**併記は著者性を与えない。免責にもならない。

そして、この体系は AI を著者にしていない。それは方針として書いてあるだけで、
書いてあること自体は何の保証にもならない。

### それでも残ること

開示を盾に使っていないことは、**開示そのものの不足を自分で記録している**ことで
見える。二件ある。

| | |
| --- | --- |
| `E5` | 三篇の開示文は AI にさせた作業を列挙している。その列挙に翻訳が無い。英文は AI 翻訳である |
| `E7` | M の開示文が「AI は捏造していない」と断言している。同じ段落が、参考文献の照合も AI がやったと述べている。著者は原典に当たっていないので、この断言は AI 自身の報告に乗っている |

加えて `E6` —— 引用した原典に著者は当たっていない。英語版の README には
`The papers were not independently derived by a human` と書いてある。

**併記で足りると考えている書き手は、この三つを自分からは書かない。**

### この答えの崩し方

開示が、実際にさせた作業より狭く読めるように書かれている箇所を一つ示す。
あるいは `E5`・`E6`・`E7` のいずれかが消されたことを示す。消えれば検査が落ちる。

## 反論 3 —— 「人権宣言でもしてるつもりか」

### 認めるところ

**語調については当たっている。**「個人帝国主義」「マニフェスト」「高貴さ」「範例」。
大きい語である。

**この語調は擁護しない。**凍結された紙面のものであり、もう直せない。

### それでも残ること

語調と射程は別である。射程は紙面自身が狭く切っている。

| | |
| --- | --- |
| 皇帝主義 | `strictly reflexive`（反照的のみ）。他者への支配を含まないと冒頭が明示している |
| 独身論 | 結論は `exemplary`（範例）であって、普遍的な義務ではないと第5節が明示している |
| 断章論 | 断片は修復すべき傷ではなく、住まうための規律の対象である。他人に課していない |

三篇とも、他者に義務を課していない。**宣言の形をとっていない。**

記録の側の語調は、紙面とは別に定めてある。自称の肩書きは機械で禁止してあり、
禁じた語は各リポジトリの `check_text` に並べてある。外部の評価を査読とも呼ばない。

### この答えの崩し方

三篇のいずれかが、自ら宣言した射程を超えて他者に義務を課している箇所を一つ示す。
あるいは、記録の側が `check_text` の禁じた語を使っている箇所を一つ示す。

## 反論 4 —— 「これは実験なんでしょ？」

### 認めるところ

**当たっている。実験の体をなしていない。**

実験と呼ぶなら、仮説と手続きと失敗条件が先に要る。ここは違う。**先に論文として
公開し、あとから実験の枠を掛けた。**`ROUTE.md` の九段階のうち六段階は再構成であり、
この系列で起きたことを「数学的再発見」と規定したのは、最終段階の 2026年9月8日である。

**だからこの記録は、自らを実験とは呼んでいない。**呼べば、先に置いていなかったものを
先に置いていたことにする。

### それでも残ること

**枠を後から掛けたことと、経路が残っていることは別である。**

| | |
| --- | --- |
| 後から掛けたもの | 「数学的再発見」という規定、九段階という整理 |
| 後から掛けられないもの | 凍結された PDF の日付（Zenodo が持つ）、git の履歴 |

段階 1〜6 は Zenodo の PDF、段階 7〜9 は git の履歴に紐づいている。
**どちらも著者が書き換えられない。**経路を都合よく引き直すことはできない。

そして再構成であることは、隠さずに `ROUTE.md` に書いてある —— 九段階のうち六段階が
再構成で、同時に記録したのは三段階だけである。**その時点で何を考えていたかは推定で
あって記録ではない、とも書いてある。**

### この答えの崩し方

日付の順序が実際と違う例を一つ示す。あるいは、同時記録だと書いてある段階 7・8・9 の
いずれかについて、git の履歴がそれより後であることを示す。

## この文書の限界

**三つとも、答えたのは反論の一部である。**

反論 1 の核 —— 内容に価値があるか —— には答えていない。答えられない。
`ST-002` が `open` のまま置いてあるのは、そのためである。

**ここに書いたのは、反論が指している弱点のうち、機械で確かめられる範囲だけである。**
確かめられない範囲は、確かめられないと書いてある。
