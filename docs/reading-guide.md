# この記録の読み方

十年後に読む人のための頁です。
2026-11-11 に置きました。
何が正で、どこに何があるかを短く並べます。
百本ノック四の 309 の答えです。

## 何が正か

同じ中身が何か所にもあります。
どれを正とするかは [正本の優先順位](canonical-sources.md) が決めています。
要点は三つです。

1. 論文の本文と書誌の正は Zenodo の DOI です。GitHub の PDF は控えです
2. 公開したあとの誤りの正は、各リポジトリの正誤表と、訂正の登録簿（`self-correction`）です
3. 数の正は検査です。散文に書いた数は、検査が実物と突き合わせています

公開済みの PDF は凍結しており、書き換えていません。
PDF と正誤表が食い違えば、正誤表のほうが新しい判断です。

## 読むときに気を付けること

日付は二通りあります。
出来事が起きた日と、記録に書いた日です。
訂正の登録簿は、この二つを分けて持っています。

言語モデルを使って作っています。
どの作業に何を使ったかは、各リポジトリの README の「言語モデルの使い方」の表にあります。
言語モデルは著者ではありません。

肩書きは名乗っていません。
書き手は、これを書いた時点で一学部生です。
