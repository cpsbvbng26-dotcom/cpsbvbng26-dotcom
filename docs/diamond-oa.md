百本ノック四の 353 の答えです。
決めごと 14 が許す側の場だけを並べます。

載せる条件は一つです。
場の側の文で、掲載料も投稿料も取らないことと、読むのに金が要らないことを、こちらで実際に取り寄せて読めたものだけを載せます。
作業環境から届くのは GitHub だけです。
場の文が GitHub に置かれていない場は、確かめられないので載せていません。
載っていないことは、その場が有料だという意味ではありません。

ここに載せることは、出すと決めたことではありません。
出す先は、決めごと 15 の範囲（学部一年次の成果の続きか修正、または JOSS などの経路）で、その都度決めます。
