# スクリーンリーダーで読み上げた結果

機械の検査では分からないところを、実際に読み上げて確かめた結果の記録です。
2026-11-11 に、記録の様式だけを置きました。
まだ一度も読み上げていません。
百本ノック四の 330 の答えです。

作業環境には読み上げの道具がなく、こちらでは読み上げられません。

## 様式

一回の確かめを一行にします。
「確かめた人」は、読み上げた人の続柄や名前ではなく、役割で書きます（利用者、読者など）。

| 日付 | 頁 | 道具と版 | ブラウザと版 | 確かめたこと | 結果 | 直したこと | 確かめた人 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| （まだ無い） | | | | | | | |

## 確かめること

頁ごとに、次の六つを聞きます。

1. 頁の題が、最初に読み上げられるか
2. 「本文へスキップ」で本文に飛べるか
3. 見出しの並び（h1 → h2）が、見出しの一覧で順に出るか
4. 表の見出しの欄が、欄の名として読み上げられるか
5. 画像の代替テキストが、何の画像かを言っているか
6. 言語の切り替えのリンクが、切り替え先の言語の名で読み上げられるか

## 最初に確かめる頁

トップの頁（日本語と英語）、作品の目録、作用素の頁の四つです。
