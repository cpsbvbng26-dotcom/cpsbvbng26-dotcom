# 障害の記録

サイトが落ちた、検査が誤った、配った中身が食い違った、といった出来事を、いつ・何が・どう直したかの三つで並べた記録です。
2026-11-11 に置きました。
百本ノック四の 318 の答えです。

公開物そのものの誤りは、ここには書きません。
それは各リポジトリの正誤表と、[訂正の登録簿](https://github.com/cpsbvbng26-dotcom/self-correction)に書きます。
ここに書くのは、運営の側で起きたことです。

日付は、直したコミットの日付です。
git の履歴から取りました。
起きた時点の記録ではないものは、その旨を書きます。

たとえば、参考文献の宣言が本文に出ているかを見る検査は、参考文献欄の行に文字列があれば通る作りでした（登録簿の `PH-010`、2026-09-08）。

## 書き足し方

新しい出来事は、表の下に一行足します。
番号は I の続きにし、消しません。
直していないものは、「どう直したか」の欄に「直していない」と書きます。
