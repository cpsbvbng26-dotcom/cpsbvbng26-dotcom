DOI ANALYZER

DOI や SSRN の Abstract ID を入れると、Crossref・OpenAlex・Semantic Scholar・DataCite に問い合わせて収録の有無と被引用数を実際に取得します。あわせて、手動で確認するためのリンクも生成します。

受け付ける形式: DOI（10.2139/ssrn.1234567）、DOI の URL、SSRN の Abstract ID（数字のみ）、 SSRN や Zenodo のページ URL、論文タイトル。

調査結果

各サービスの公開 API に問い合わせた結果です。

確認先

API を持たないサービスも含めた、手動で確認するためのリンクです。新しいタブで開きます。
