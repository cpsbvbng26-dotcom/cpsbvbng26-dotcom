# 開示できない開示 —— AI 利用の申告は、意志ではなく記録で止まる

**下書き**。まだ公開していない。出す先の候補は MetaROR である。

---

## 主張

生成 AI の利用開示について、いま数えられているのは「書いたかどうか」である。
「書けたかどうか」は数えられていない。

方針の側は、名称・版・製造元・使い方を求める方向へ動いている。
**道具の側は、そのどれも利用者に残さない**。対話の画面は版を表示せず、
背後の模型は予告なく入れ替わり、履歴は既定では書き出せない。

**意志があっても申告できない場合がある**。開示率の低さは、意志の問題として
読まれている。その一部は、能力の問題である可能性がある。

## この主張の出どころ —— 自分の失敗である

著者は哲学の三篇を公開している。英文は AI による翻訳である。
どの道具を使ったかを特定できない。

| | |
| --- | --- |
| 記録 | 残っていない |
| 著者の記憶 | 定まらない |
| いま書いてあること | 「特定できない」と、正誤表の `E5` に書いてある |

**隠したのではない**。開示しようとして、開示する材料が無いことが分かった。

そして、この一件は**公開されている**。正誤表に残してあり、査読誌に出した
ときも編集者への開示文に同じことを書いた。「何を使ったか再構成できない」
と書くことが、分かっていることの全部を書くことである。

## いま分かっている外の数

**いずれも原典を読んでいない**（`検索で確認（原典未読）`）。
出すときは原典に当たる。

| | |
| --- | --- |
| 5,114 誌の約 70% が生成 AI の方針を持つ。75,172 本のうち開示が付いていたのは約 0.1% | PNAS、2026年3月。He・Bu（北京大学） |
| ある放射線科の誌で、開示率は 1.1%（2024）→ 2.5%（2025）→ 7.5%（2026） | 編集長による報告 |
| 医学研究者 2,000 名の調査で 45% が AI を使用。うち約三分の二が原稿の執筆・編集に用いた | 調査 |
| JAMA の 2026 年の指針は、AI の名称・版・製造元・使い方を書かせる | JAMA |
| Science / AAAS は名称・版に加え、場合によってはプロンプトまで求める | AAAS |

方針の 70% と、開示の 0.1% の差が、この論文の対象である。
その差は不履行として読まれている。そこに、履行できない場合が混じっている。

## なぜ履行できないのか

四つある。どれも著者の側で直せない。

1. **版が見えない**。対話の画面は、いま応答している模型の版を表示しないことが多い。
2. **版が黙って変わる**。同じ名前の製品が、予告なく別の模型に入れ替わる。
   使った時点の版は、あとから確かめられない。
3. **履歴が残らない**。既定で書き出せない。消える場合もある。
4. **翻訳や下書きは、道具を跨ぐ**。どの一文がどの道具から来たかは、
   使った本人にも分解できない。

方針は「名称・版・製造元」を一つの欄に書かせる。
上の四つは、その欄を埋められなくする。

## 測れる形にする

主張を、数えられる形に落とす。

| 問い | 測り方 |
| --- | --- |
| 方針は何を求めているか | 主要な誌の方針を読み、要求される項目を数える。名称だけか、版まで求めるか |
| 道具は何を残すか | 主要な対話型の道具について、版の表示・履歴の書き出しの可否を調べる |
| 差はどこにあるか | 「求められている項目」から「道具が残す項目」を引く |

三つ目が出れば、開示できない範囲が寸法として出る。

## この下書きに足りないもの

**事例が一件しかない**。著者自身の `E5` である。

**同じ形の事例を集める必要がある**。ただし、**特定の著者や誌を名指しして
「開示を怠った」と書くことはしない**。書けるのは、公表された撤回・訂正の
告知と、集計された調査だけである。

そして**上の外の数は、どれも原典を読んでいない**。出す前に当たる。
