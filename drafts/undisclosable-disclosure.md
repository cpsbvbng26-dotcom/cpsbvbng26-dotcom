# 開示できない開示 —— AI 利用の申告は、意志ではなく記録で止まる

**下書き**。まだ公開していません。出す先の候補は MetaROR です。

---

## 主張

生成 AI の利用開示について、いま数えられているのは「書いたかどうか」です。
「書けたかどうか」は数えられていません。

方針の側は、名称・版・製造元・使い方を求める方向へ動いています。
**道具の側は、そのどれも利用者に残しません**。対話の画面は版を表示せず、
背後の模型は予告なく入れ替わり、履歴は既定では書き出せません。

**意志があっても申告できない場合があります**。開示率の低さは、意志の問題として
読まれています。その一部は、能力の問題である可能性があります。

## この主張の出どころ —— 自分の失敗である

著者は哲学の三篇を公開しています。英文は AI による翻訳です。
どの道具を使ったかを特定できません。

| | |
| --- | --- |
| 記録 | 残っていない |
| 著者の記憶 | 定まらない |
| いま書いてあること | 「特定できない」と、正誤表の `E5` に書いてある |

**隠したのではありません**。開示しようとして、開示する材料が無いことが分かりました。

そして、この一件は**公開されています**。正誤表に残してあり、査読誌に出した
ときも編集者への開示文に同じことを書きました。「何を使ったか再構成できない」
と書くことが、分かっていることの全部を書くことです。

## いま分かっている外の数

出すときは原典に当たります。

| 5,114 誌の約 70% が生成 AI の方針を持っています。75,172 本のうち開示が付いていたのは約 0.1% | PNAS、2026年3月。He・Bu（北京大学） |

方針の 70% と、開示の 0.1% の差が、この論文の対象です。
その差は不履行として読まれています。そこに、履行できない場合が混じっています。

## なぜ履行できないのか

四つあります。どれも著者の側で直せません。

1. **版が見えません**。対話の画面は、いま応答している模型の版を表示しないことが多い。
2. **版が黙って変わる**。同じ名前の製品が、予告なく別の模型に入れ替わる。
   使った時点の版は、あとから確かめられません。
3. **履歴が残りません**。既定で書き出せません。消える場合もあります。
4. **翻訳や下書きは、道具を跨ぐ**。どの一文がどの道具から来たかは、
   使った本人にも分解できません。

方針は「名称・版・製造元」を一つの欄に書かせます。
上の四つは、その欄を埋められなくします。

## 測れる形にする

主張を、数えられる形に落とす。

| 問い | 測り方 |
| --- | --- |
| 方針は何を求めているか | 主要な誌の方針を読み、要求される項目を数える。名称だけか、版まで求めるか |
| 道具は何を残すか | 主要な対話型の道具について、版の表示・履歴の書き出しの可否を調べる |
| 差はどこにあるか | 「求められている項目」から「道具が残す項目」を引く |

三つ目が出れば、開示できない範囲が寸法として出ます。

## この下書きに足りないもの

**事例が一件しかありません**。著者自身の `E5` です。

**同じ形の事例を集める必要があります**。ただし、**特定の著者や誌を名指しして
「開示を怠った」と書くことはしません**。書けるのは、公表された撤回・訂正の
告知と、集計された調査だけです。

そして**上の外の数は、どれも原典を読んでいません**。出す前に当たります。
