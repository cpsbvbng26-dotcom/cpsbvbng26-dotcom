# Vercel に出している中身

**ここにあるのは、`cpsbvbng26-dotcom.vercel.app` に配備したファイルそのものである。**
サイトの中身ではない。正本 —— GitHub Pages —— へ送り返すだけの二枚である。

| ファイル | 役割 |
| --- | --- |
| `vercel.json` | あらゆる経路を `github.io` の同じ経路へ送る（307。戻せる向きである） |
| `index.html` | 上が効かなかったときの受け皿。`meta refresh` と一本のリンクだけ |

## なぜ写しを置かず、送り返すのか

**写しは古くなる。**2026年9月17日、利用者が Vercel 側に前の科目名が残っていることを
確かめた。GitHub との連携が切れており、push に追随していなかった。

送り返す側には、古くなる中身が無い。

## 直し方

この作業環境から Vercel の設定は読めない —— プロジェクトの取得も配備の一覧も 403 で
返る。書き込みだけが通る。**中身を変えるときは、この二枚を直して配備し直す。**
`vercel.json` の宛先は `sitemap.xml` の `<loc>` と同じ土台を指す。
