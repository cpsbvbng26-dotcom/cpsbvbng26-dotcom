Machine-readable forms, and how the columns are decided

The same content is also published as JSON and BibTeX.

Catalogue as BibTeXRecords for the works with a DOI, ready for a reference manager

Which copy is canonicalThe canonical location follows the rules on which copy is canonical: Zenodo is canonical for the PDF and bibliographic record of a paper; GitHub is canonical for implementation and version history; a Zenodo archive is a copy at one point in time; The public entrance is canonical on Vercel; For a text not on Zenodo, its present location is canonical; ERRATA.md is canonical for withdrawals and corrections.

DisclaimerThe licence column is generated from the LICENSE layout of the repository that holds the work. For a work not held in a repository, the licence shown by its record applies.

Source (catalog.json)This page, the JSON and the BibTeX are generated from catalog.json in researcher-profile. The Zenodo resource type is the resource type registered with DataCite. A check compares it with the DataCite record. Frozen applies to the published papers and versions. Errata and checks may still be added. The period begun is taken from the first commit of the repository that holds the work. The second undergraduate year began in October 2026.
