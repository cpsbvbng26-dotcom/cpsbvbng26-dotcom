✴︎Projects✴︎

**厨二病ジェネレーター** — [デモ](https://cpsbvbng26-dotcom.github.io/chuuni.html) ・ [ソース](./chuuni.js)

技名・二つ名・組織名・詠唱・キャラクター設定書を一度に最大 300 件生成する静的 Web アプリ。

- 素の JavaScript のみで実装し、外部ライブラリ・CDN への依存はゼロ
- FNV-1a ハッシュ + mulberry32 による疑似乱数で、同じシードから同じ結果を再現
- 独自のマーカー記法から `<ruby>` とプレーンテキストを描き分け、漢字にカタカナルビを付与
- 技名の最長パターンだけで約 55 万通りの組み合わせ
- 一括コピー、`.txt` / `.json` 書き出し、URL ハッシュによる生成条件の共有に対応

**個人サイト / ポートフォリオ** — [cpsbvbng26-dotcom.github.io](https://cpsbvbng26-dotcom.github.io/)
