機械で読む形と、列の決め方

同じ中身を、JSON と BibTeX でも配っています。

目録の JSON題・種類・状態・DOI・正の所在・ライセンス・Zenodo の資源の種類・始めた時期を、作品ごとに

目録の BibTeXDOI を持つ作品の書誌。引用の管理の道具にそのまま取り込めます

正本の優先順位正の所在は、正本の優先順位の決めに従います：論文の PDF と書誌は Zenodo が正。実装と版管理は GitHub が正。Zenodo の保存版は特定の時点の写し。公開の入口は Vercel が正。Zenodo に無い本文は、いまの所在が正。撤回と正誤は ERRATA.md が正。

免責事項ライセンスの列は、置いてあるリポジトリの LICENSE の置き方から出しています。リポジトリに置いていない作品は、置き場の記録の表示に従います。

生成もと（catalog.json）この頁と JSON と BibTeX は、researcher-profile の catalog.json から生成しています。Zenodo の種類は、DataCite に登録された資源の種類です。検査が DataCite の記録と突き合わせます。凍結は、公開した論文と版を指します。正誤表と検査は、凍結のあとも足します。始めた時期は、作品を置いたリポジトリの最初のコミットの日付から出しています。学部二年次は 2026 年 10 月からです。
